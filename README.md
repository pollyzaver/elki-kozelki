# Ёлки-козёлки!

Интерактивная новогодняя игра для семейного застолья — на русском и английском.
A bilingual (Russian / English) New Year party game for the whole family.

## Что внутри

- **Главный экран** — козочка-маскот, которая следит глазами за курсором, моргает и разговаривает.
- **Команды** — от 2 до 8 команд, свои названия и цвета.
- **Раунд «Кто ближе?» / Closest wins** — ответ на каждый вопрос — число, очко получает команда, назвавшая самое близкое. Точное попадание — 2 очка. Есть отдельный набор вопросов про Новый год в Италии и Греции.
- **Итоги** — пьедестал победителей.

Прогресс игры сохраняется в браузере, так что случайно закрытая вкладка ничего не сломает.

## Как запустить

Просто открой `index.html` в браузере — сервер и установка не нужны.
